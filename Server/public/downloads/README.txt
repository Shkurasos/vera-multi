Положите сюда установщики Vera Desktop:
  - Vera-Setup-<version>.exe    (Windows, NSIS)
  - Vera-<version>.dmg          (macOS)
  - Vera-<version>.AppImage     (Linux)

Всё содержимое этой папки автоматически раздаётся по /downloads/<file>
и попадает в список GET /api/downloads. Файлы, начинающиеся с '.', игнорируются.
