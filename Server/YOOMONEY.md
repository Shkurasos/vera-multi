# Пополнение ВП через ЮMoney

Курс: 1 ₽ = 2 ВП. Форма принимает целые суммы 25–25000 ₽.
Комиссия сервиса удерживается из поступления владельцу, не из ВП пользователя.

1. Создайте кошелёк ЮMoney и пройдите необходимую идентификацию. До запуска
   согласуйте с сервисом приём платежей за виртуальные предметы/ВП, требования
   к вашему статусу и чекам. Это не обязательно безвозмездное пожертвование.
2. В `Server/.env` задайте `YOOMONEY_RECEIVER` (номер кошелька) и
   `YOOMONEY_NOTIFICATION_SECRET` (секрет HTTP-уведомлений). Не передавайте
   секрет клиенту и не публикуйте `.env`.
3. В настройках HTTP-уведомлений ЮMoney включите отправку на публичный HTTPS URL:
   `https://ВАШ-ДОМЕН/api/wallet/yoomoney/webhook`.
4. Перезапустите сервер и пересоберите клиент. В инвентаре создайте платёж,
   нажмите «Оплатить картой через ЮMoney». Возврат из формы не начисляет ВП:
   начисление происходит только по подписанному уведомлению HMAC-SHA256.
5. Проверьте небольшой реальный платёж, повторную доставку уведомления и
   фактическую возможность перевода из кошелька на вашу российскую карту.
   Вывод выполняется вами в ЮMoney, не в VERA. Доступность конкретных карт,
   лимиты, комиссии и требования к идентификации определяет ЮMoney.

Заказы сохраняются для защиты от повторного начисления. Не удаляйте оплаченные
заказы. При недоставленном уведомлении сверяйте историю кошелька: ЮMoney
делает ограниченное число попыток доставки. Автоматические возвраты и сверка
истории операций не реализованы. Для P2P-режима нужен центральный сервер.

Документация:
- https://yoomoney.ru/docs/payment-buttons/using-api/forms
- https://yoomoney.ru/docs/payment-buttons/using-api/notifications
- https://yoomoney.ru/transfer

Старый mock-pay по умолчанию закрыт и всегда запрещён в production или при
настроенном ЮMoney. Криптовалютный webhook без секрета тоже закрыт.
