# 🔧 Исправления: прочтение сообщений, избранное, онлайн-статус, двойные галочки

## Проблемы, которые были

1. **Избранное (favorites) всегда показывало `unreadCount: 0`** — даже если в чате были непрочитанные сообщения
2. **Сообщения не помечались как прочитанные автоматически** при открытии чата — только одна галочка вместо двух
3. **Онлайн-статус мигал "через раз"** — при кратковременном разрыве связи пользователь сразу помечался оффлайн
4. **Клиент не обрабатывал `messages:read_all`** — сервер шлёт событие при открытии чата, но клиент его не слушал

---

## ✅ Исправления на сервере (Server/server.js)

### 1. Favorites — реальный `unreadCount` (строка ~5754)
**Было:** `unreadCount: 0` всегда  
**Стало:** Подсчет реальных непрочитанных сообщений.

### 2. Автоматическое прочтение при открытии чата (событие `chat:join`)
Когда пользователь открывает чат, сервер помечает все непрочитанные сообщения как прочитанные и шлёт `messages:read_all` всем участникам.

### 3. Онлайн-статус с грейс-периодом 30 секунд
При кратковременном разрыве связи статус не мигает — пользователь остаётся онлайн 30 сек before перехода в оффлайн.

## ✅ Исправления на клиенте (Web/src)

### 1. App.tsx — обработчик `messages:read_all` (строки ~480-487)
Клиент теперь слушает событие от сервера и обновляет `readBy` у всех сообщений чата:
```ts
socket.on('messages:read_all', ({ chatId, userId }) => {
  if (userId === user?.id) return;
  setTimeout(() => {
    useChatStore.getState().markAllMessagesRead(chatId, userId);
  }, 0);
});
```

### 2. chatStore.ts — новая функция `markAllMessagesRead`
Помечает все сообщения в чате как прочитанные дляgiven пользователя (добавляет `userId` в `readBy` у каждого сообщения).

### 3. chatStore.ts — `markRead` теперь обновляет `readBy` локально
Раньше функция только отправляла запрос на сервер и обнуляла счётчик. Теперь она сразу добавляет текущего пользователя в `readBy` сообщения:
```ts
const meId = useAuthStore.getState().user?.id;
if (meId) {
  get().markMessageRead(chatId, messageId, meId);
}
```

## 📋 Как это работает (цепочка)

1. Пользователь öffnet чат → клиент шлёт `chat:join` (уже было в `setActiveChat`)
2. Сервер помечает все непрочитанные сообщения как прочитанные для этого пользователя
3. Сервер шлёт `messages:read_all` с `chatId` и `userId`
4. Клиент получает событие → вызывает `markAllMessagesRead(chatId, userId)` → добавляет `userId` в `readBy` у всех сообщений чата
5. `MessageBubble` видит `readByOthers.length > 0` → показывает двойную галочку (DoneAll)

Также при отправке `markRead` для отдельного сообщения (при фокусе окна или при получении нового сообщения), клиент сразу обновляет `readBy` локально, не дожидаясь сервера.
